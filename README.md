# Gamified Carpool Driver Panel

This is a prototype Streamlit demo for a gamified driver-side carpool matching dashboard.

## Features
- Synthetic passenger generation
- Pickup radius filtering
- Route visualization
- Passenger selection
- Commute scoreboard
- XP, coins, badges, fairness, offset, and CO2 saved
- Simulated email workflow

## How to run locally
pip install -r requirements.txt
streamlit run app.py
